## 🧰 Installiamo Visual Studio Code

<div v-click>

Per scrivere le nostre **prime righe di codice HTML**,
abbiamo bisogno di un **editor di testo professionale** ma semplice da usare.
</div>

<div v-click>

👉 Il più diffuso (e gratuito) è **Visual Studio Code**, sviluppato da Microsoft.
</div>

<div v-click>

### 🔹 Cosa fare ora:
1. Vai sul sito ufficiale → [https://code.visualstudio.com](https://code.visualstudio.com)
2. Scarica la versione per il tuo sistema operativo (Windows, macOS o Linux)
3. Installa seguendo i passaggi guidati
4. Apri **VS Code** e tienilo pronto per scrivere il tuo primo file `.html`
</div>

<div v-click class="mt-10 text-gray-400 italic text-lg text-center">
💡 Con VS Code potrai scrivere, colorare e vedere il tuo codice in azione.<br>
È lo strumento che useremo per tutto il resto della lezione.
</div>
